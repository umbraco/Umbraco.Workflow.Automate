# Upgrade to Umbraco 19

From `18.0.1` to `19.0.0-rc1`.
Branch `v19/dev`, cut from `origin/main` at `0dafeea` on 17-11-2026, the same long-lived line as
the other Automate satellites.

**Targets CMS release:** `19.0.0-rc1` (tag `release-19.0.0-rc1`, GitHub pre-release of
12-11-2026). It's still the newest CMS 19 release on 17-11-2026. This is a pre-release, so the
package ships as `19.0.0-rc1`, following Automate core and the other satellites.
